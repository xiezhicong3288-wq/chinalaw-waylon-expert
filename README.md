# chinalaw-waylon-expert

这是一个供 Codex 等支持本地 Skill 的 AI 助手使用的中文法律检索技能，收录十部法律的统一知识库。

## 案件研究升级（2026-09-25）

新增案件目标与争点拆解、证据对照表、双方论点复核、法律版本核验、类案差异比较，以及带验证和回滚的改进流程。

案例学习样本目前只有两个：指导案例15号（关联公司人格混同）和指导性案例273号（技术秘密、赔偿与执行）。案例卡包含官方来源、裁判日期、案号和适用边界，是编辑摘要，不是完整案卷或律师亲历经验。

改进由明确的更新或复盘任务触发，不自动在后台运行，也不修改底层模型。原始用户案卷默认不进入公开仓库。尚未经过执业律师全面评审。

验证命令（Python 3.10+，仅使用标准库）：

```text
python scripts/validate_knowledge_base.py
python -m unittest discover -s tests -v
```

模型行为测试另见 `evals/README.md`。自动测试通过不等于法律分析已经正确，也不代表达到顶级专家水平。

本次实际执行结果见 [2026-09-25验证记录](evals/reports/2026-09-25.md)：13项工具测试通过，独立执行的10道合成问题按列明标准复核通过。报告同时列出未测项目；未进行专业律师认证或旧版模型表现对比。

## 一句话安装

在 Codex 中输入以下提示词：

```text
请使用 skill-installer 从 GitHub 仓库 https://github.com/xiezhicong3288-wq/chinalaw-waylon-expert 安装这个 Skill。
```

也可以下载 ZIP 或克隆仓库，再将完整目录安装到工具的 Skill 目录。必须保留 `SKILL.md`、`references/` 和 `scripts/` 的相对位置；只复制 `SKILL.md` 无法使用法律原文库。

## 使用示例

```text
请使用 chinalaw-waylon-expert 查询刑法第390条，引用原文并解释。
请检索“七日无理由退货”涉及哪些消费者权益保护法条文。
公司未缴社会保险，我需要保存哪些证据？请先检索原文再分析。
行政处罚决定可以怎样申请救济？请区分行政处罚法和行政诉讼法。
请用该 Skill 分析案件，列出争点、待证事实、现有证据和对方最强抗辩。
请比较事实发生时与当前的法律版本，并明确尚未核验的依据。
```

## 文件结构

- `SKILL.md`：技能入口、约束和检索流程。
- `references/law-catalog.json`：十部法律的版本和路径目录。
- `references/law-index.json`：统一条文索引。
- `references/source-manifest.json`：新增法律的来源和校验信息。
- `references/民法典/`、`references/法律法规/`：法律原文。
- `scripts/search_law.py`：确定性检索工具。
- `scripts/validate_knowledge_base.py`：知识库一致性检查。
- `references/workflows/`：案件、证据、版本、案例与持续改进流程。
- `references/cases/catalog.json`：官方案例学习样本目录。
- `evals/` 与 `tests/`：模型行为任务和检索回归测试。

## 数据来源与使用边界

新增九部法律均按政府机关公开的法律全文整理，具体网址记录在各原文文件头部和 `references/source-manifest.json`。知识库整理日期为 **2026年9月24日**，不会自动更新；实际案件应再次核验国家法律法规数据库、最新司法解释和适用的地方规定。

本技能用于法律原文检索和一般性解释，不替代律师意见，也不保证案件结果。请勿在公开 Issue 中提交身份证号、联系方式、未脱敏合同或案件材料。
