# 中华人民共和国民法典检索 Skill

一个面向支持本地 Skill 的 AI 助手的中文技能，提供民法典条文查询、关键词检索、通俗解释和基础民商事问题分析。核心要求是先读取本地法律原文，再引用和解释，避免凭模型记忆编造条文。

## 文件内容

- `SKILL.md`：技能入口、适用范围和检索流程。
- `references/article-index.json`：1260 条条文的结构化索引。
- `references/民法典/`：目录及各编原文。
- 其他参考目录：仅有占位说明，尚未收录司法解释、案例或法律文书。

## 安装和使用

1. 在本仓库页面选择 **Code → Download ZIP**，或使用 Git 克隆仓库。
2. 将解压后的文件夹命名为 `china-civil-code-expert`，保留 `SKILL.md` 与 `references/` 的相对位置。
3. 按所用 AI 工具的 Skill 安装说明，将整个文件夹放入其技能目录或通过其导入功能安装。
4. 在支持读取本地文件的会话中启用该技能，然后提出问题。

只有粘贴 `SKILL.md` 的内容无法提供完整知识库；必须同时安装 `references/`。不同工具的技能目录和启用方式可能不同，请以对应工具的说明为准。技能中的 `Grep/Read` 指文本搜索和文件读取能力，可由工具提供的等效功能完成。

示例问题：

```text
请使用 china-civil-code-expert 查询民法典第577条，引用原文并解释。
请检索“定金”相关条文，区分法律原文和你的解释。
对方收了货款却没有发货，请先列出需要确认的事实，再检索相关条文。
```

## 来源与适用边界

原文文件中保留了资料来源、下载日期及版本说明。索引用于定位，引用时应读取对应原文文件。

该知识库是静态资料，不会自动更新。当前发布整理检查文件结构与索引关联，并不代表重新逐字核验全部原文或确认所有法律资料的最新效力。涉及实际案件时，应核验现行有效规定及相关司法解释。

本技能提供检索和一般性解释，不替代律师意见，也不保证案件结果。请避免在公开 Issue 中提交身份证号、联系方式、未脱敏合同或案件材料。
