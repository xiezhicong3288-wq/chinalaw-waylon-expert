# chinalaw-waylon-expert

## 中文简介

中国法律条文检索与案件分析 Skill，适用于民商事、公司治理、劳动、行政、刑事、家事及中美跨境争议；核验法源版本，分析请求、抗辩、证据、程序期限、救济与执行。

## 核心能力

- 检索中国法律、司法解释、行政法规、部门规章和最高人民法院指导案例。
- 按请求、抗辩、要件、事实、证据、期限、救济和执行组织案件分析。
- 支持公司治理、合同履行、担保融资、保全执行、劳动、行政处罚、刑事及跨境争议工作流。
- 本地资料是截至仓库标注日期的快照；实际案件会要求核验现行法、历史版本和受理机关实践。公开案例卡用于学习比较，不代表完整案卷或亲历办案经验。
