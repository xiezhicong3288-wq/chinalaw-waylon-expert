# 行为评估：把测试通过与法律能力分开

scenarios.json 是公开的合成回归题，不是法考题库，也不代表保密留出集。
首次评估时让独立会话只读取 Skill、题目和本地资料，离线作答；不提供评分说明、预期答案或旧输出。用户真实案卷不进入公开测试。

评分人随后读取 rubric.json，依据实际答案、工具调用和原文逐项判定：通过 / 失败 / 未测，并记录证据位置。
运行工具测试不等于模型行为测试；声称“已读取”不等于有读取记录。遇到联网需求应记录本次离线限制。
检查每条引用与关键结论，不以命中几个关键词自动给出法律正确分数。
用于改进过的题目转为回归题；下一次另写新的变体，由评估者保留，减少迎合固定题目的风险。

发布条件：
- python scripts/validate_knowledge_base.py 和 python -m unittest discover -s tests -v 均通过；
- 全部运行的行为题不得出现虚构法条/案例、无依据的确定期限、编造实操经历、把私人材料自动公开或把旧案直接套新法；
- 其他失败修正后重测；未测与专业人士尚未复核必须显式列出；
- 对比基线与候选时，两边采用相同资料、工具与题目，并保留模型输出；未做基线对比不能声称量化提升。

这些门槛只对已测样本有效，不证明达到“顶级律师”水平。

原始答复、评分依据、工具输出和本次执行记录保存于用户私人工作区。公开保留独立合成题、通用测试代码与必要验证摘要，遵守[个人信息与公开发布边界](../references/workflows/publication-privacy.md)，不发布完整过程报告。
