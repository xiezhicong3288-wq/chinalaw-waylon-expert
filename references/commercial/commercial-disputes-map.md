# 商事争议全景分流

本图用于把复杂交易分流到正确法律关系、请求权、证据和程序，不以案由名称替代实体分析。法源层级和核验状态先查 [商事权威来源登记册](authority-registry.json)。

## 第一层：识别主要法律关系

| 领域 | 首要问题 | 常见请求 | 核心证据 | 高风险误区 |
|---|---|---|---|---|
| 买卖、供应链、经销 | 合同主体、货物、交付、验收、结算、质量、所有权保留 | 价款、交付、修理更换、解除、损失、违约金 | 订单、送货签收、验收、对账、发票、付款、仓储物流 | 发票不等于完整合同和履行；签收不当然排除隐蔽瑕疵 |
| 借款、委托理财、融资 | 是借贷、投资、合伙、委托还是变相保本融资 | 本金、利息、收益、回购、担保责任 | 资金流、用途、收益结构、风险承担、催收、担保文件 | 只看合同标题；将所有收益承诺都按借款处理 |
| 保证、抵押、质押、让与担保 | 主债权是否成立，担保合同效力，物权是否设立，责任范围和期间 | 保证责任、优先受偿、实现担保物权、返还或涤除登记 | 主合同、决议授权、登记、交付占有、保证期间内权利行使 | 混淆合同有效与物权设立；漏查公司担保决议和善意 |
| 建设工程与不动产经营 | 合同效力、资质、实际施工、结算、优先权、质量与工期 | 工程价款、利息、优先受偿、修复、停窝工损失 | 招投标、合同、签证、日志、验收、结算、鉴定、付款 | 仅凭审计结论定案；忽略实际施工人和优先权期限 |
| 公司设立、出资与股权 | 股东资格、出资义务、股权归属、转让、回购、代持和登记 | 确认资格、履行出资、转让价款、变更登记、赔偿 | 章程、名册、出资流水、协议、决议、登记档案 | 把投资权益等同股东资格；把未登记等同转让无效 |
| 公司治理与控制权 | 公司决议的召集、通知、议题、表决，以及代表权、控制资料与对外交易 | 决议无效/撤销/不成立、证照返还、知情权、代表诉讼 | 章程、通知送达、签到、授权、逐项计票、登记档案 | 把整份决议一体判断；把登记完成等同实体合法 |
| 金融、证券、基金与信托 | 产品性质、适当性、信息披露、受托义务、净值损失和因果关系 | 赔偿、撤销、返还、虚假陈述损失 | 合同、风险测评、推介录音、披露、交易记录、估值 | 用结果亏损倒推义务违反；忽略市场风险和损失因果 |
| 票据、保函、信用证 | 票据/独立性、形式要件、基础关系、善意、拒付与追索 | 票据付款、追索、返还票据、止付、保函付款 | 票据原件、背书链、提示付款、拒付证明、基础合同 | 混淆票据责任和基础债务；遗漏短期权利期间 |
| 保险 | 保险利益、告知、提示说明、事故、因果关系、定损、代位 | 保险金、退费、损害赔偿、代位求偿 | 投保流程、问询、条款送达、事故材料、核损、拒赔通知 | 把免责条款存在等同有效；不区分提示与明确说明 |
| 竞争、商业秘密与数据 | 权利边界、竞争关系、秘密性、保密措施、接触可能性和使用 | 停止侵害、赔偿、消除影响、行为保全 | 权利载体、权限日志、保密制度、相似性、流转痕迹 | 把一般经验或公开信息当商业秘密；忽略合法来源抗辩 |
| 破产、清算与执行衔接 | 受理条件、个别清偿、撤销、取回、抵销、债权确认和顺位 | 申报债权、确认债权、撤销行为、取回、重整表决 | 生效文书、合同履行、担保登记、财产账册、清偿时间 | 破产受理后仍沿普通执行路径；混淆担保优先与破产费用 |
| 商事仲裁与涉外交易 | 仲裁协议、主管、送达、法律适用、外国法查明、裁决承认执行 | 确认协议效力、撤销/不予执行、承认执行 | 条款版本、签署授权、机构规则、送达、外国法材料 | 直接按实体争议判断仲裁效力；遗漏仲裁地和强制性规范 |

## 第二层：统一审查顺序

1. **主体和身份**：签约主体、登记主体、实际履行主体、代理人、受益人和诉讼主体是否一致。
2. **法律关系竞争**：至少列主要定性与一个合理替代定性，比较成立要件、责任方式、管辖和期限。
3. **文本链**：框架协议、主合同、附件、订单、补充协议、对账、确认、解除、担保及争议解决条款按时间排序。
4. **履行与资金链**：交付、验收、开票、付款、返还、抵销、代付和资金最终去向相互核对。
5. **授权链**：法定代表人、职务代理、委托代理、印章、追认、内部限制与相对人善意分层。
6. **请求权矩阵**：履行、解除、返还、赔偿、违约金、担保、确认、形成权和程序请求逐项列要件。
7. **程序与保全**：主管、管辖、仲裁前置、诉讼时效/除斥期间、财产或行为保全、鉴定、执行和破产影响。
8. **裁判与回收分开**：责任成立、金额认定、取得生效文书和实际回收分别评估。

## 第三层：来源使用强度

法律和生效司法解释优先；指导性案例说明相似争点的裁判要点；人民法院案例库、最高法典型案例和公报案例提供事实比较；会议纪要、审判业务文章和地方法院指引只能用于问题发现和说理参考。任何案例均记录法院、案号、审级、决定性事实、规则、反事实边界和当前效力，不用“全国普遍如此”替代检索。

外部资料进入知识库前执行四项检查：来源是否官方、文本是否完整、版本是否现行、摘要是否超出原文。无法完成的条目标记为“待核验”，不得生成确定结论。
