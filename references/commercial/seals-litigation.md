# 印章证照返还与公司诉讼代表

## 先审公司由谁起诉、应诉

公司是独立权利主体；识别公司直接诉讼、监事依法代表公司诉董事/高管、股东为公司利益以自己名义提起代表诉讼、股东自身权利之诉。查公司法第78、83、188、189条，并核公司法解释（四）第23—25条当前效力与新法衔接。公司法解释草案不得替代生效依据。

民事诉讼法第51条和民诉法解释第50—51条以登记法定代表人为通常诉讼代表，并允许已依法变更但尚未登记的新代表在法院准许后参加诉讼；这些规则不能单独解决“登记代表本人是被告”或两家公司由同一人代表的利益冲突。遇到冲突，先说明案件属于公司直接诉讼还是公司法第189条路径，再提交章程、任免及登记材料、形成起诉意思的机关文件、无利害关系代表或监事的身份依据和委托手续，请法院就本案诉讼代表及送达作出程序审查。不得把监事监督权直接等同于对公司所有案件的当然代表权，也不得引用公司法综合司法解释征求意见稿第54条等作为生效依据。

当被告本人也是原告公司的登记法定代表人：在起诉材料中说明身份冲突，提交监事选任及履职、股东书面请求（适用时）、侵害公司利益材料、委托手续和签署依据；是否满足特殊代表条件需法院审查，不能仅因登记身份冲突否定诉权，也不能仅凭监事身份认定所有诉讼均可代表公司。

股东代表诉讼另核书面请求、拒绝/30日未诉或紧急例外，公司诉讼地位及胜诉利益归属。有限责任公司股东不能套股份有限公司的连续180日及1%门槛。公司直接诉讼不要错误强制等待30日。

当同一自然人列为决议案原告股东公司的法定代表人，又列为被告目标公司的法定代表人，核各时点登记、任免决议效力、代表冲突、各公司独立委托和诉讼意思；不能把原告自认当成被告真实答辩。新登记代表也不能仅凭登记当然解决本案代表权争议。请求法院依法审查代表和送达问题，勿自行宣布任一方可代表双方。

建立“公司—案件—诉讼地位—登记代表—主张代表—形成诉讼意思的机关—委托律师—利益冲突”表。每一家公司独立一行；同一自然人出现在多行时分别证明授权，不能用一份签章、自认、撤诉或和解处分多家公司的权利。

## 返还请求的事实链

| 环节 | 需要证明 | 常见缺口 |
|---|---|---|
| 公司权利 | 印章或证照与公司业务、财产及管理的联系 | 姓名章未区分个人私章和公司经营印签 |
| 特定物存在 | 新旧章、名称、编码、样式、刻制/备案时间；证照正副本数量 | 只列旧章编码却请求返还新章 |
| 实际控制 | 使用原件、交接、申请人/领取人记录、实际占有与保管链 | 仅因任法定代表人推定全部物品由其持有 |
| 返还义务 | 章程、有效机关决定、保管授权、授权撤回或拒绝使用损害经营 | 只有一方催告和“股东不知情” |
| 接收执行 | 交回公司及合法指定接收人、清单、监督方式 | 监事天然取得永久保管权或个人占有权 |

逐项区分：印章真伪；刻制程序；行政备案；内部授权；民事代表行为；刑事构成。其他股东不知情不自动证明违法或犯罪，备案也不能代替公司内部授权。登报、声明和挂失不自动使全部行为无效，须核相对方收到警示的时间、内容和法律关系。

## 请求必须对应标的现状

| 请求 | 先证事实 | 常见反驳或执行问题 |
|---|---|---|
| 返还特定物 | 物仍存在、可唯一识别、由被告实际控制，公司有权接收 | 已交回、从未持有、已作废或标的描述与实物不符 |
| 停止特定使用 | 被告有现实使用或再使用风险，禁止行为足够明确 | 泛称“不得代表公司”过宽，难以确定具体行为和期限 |
| 临时封存或第三方保管 | 情况紧急、可能造成难弥补损害、与本案请求相关且措施合比例 | 担保、正常经营受损、第三方身份与交接执行不清 |
| 销毁或行政缴销 | 返还不足以排除风险，已完成鉴别、质证和证据保全，有合法执行方式 | 争议物仍需鉴定、错误销毁不可恢复、民事判决无法替登记机关作行政处置 |

营业执照已经补领、旧照已由登记机关公告作废或印章已经依法失去代表意义时，仍须分别审查返还利益、证据保存和现实滥用风险。CO11所列佛山中院普通二审判决认定取章拒还侵害经营管理权，但结合旧章遗失处理与公司更名否定返还必要性；旧章另行使用的损害未在该案审查。该个案仅提供审查变量，不构成作废物一律无需返还的规则，亦不得把侵权成立与具体救济获准等同。

姓名章另核刻制主体、印文、备案用途、购买与保管、是否为银行预留印鉴及是否兼具个人私章属性。诉请不能只写某人“姓名章”而不说明公司为何享有返还或销毁权。

补领营业执照不当然违法，原证照仍在不当然证明补领申请人明知；调取遗失声明、补领申请、授权、签字、电子提交与领照记录，比较原件持有及已知情况。

## 销毁请求应单独论证

返还、保管、停止特定使用、行政缴销与销毁是不同措施。说明公司权利、持续风险、必要性、比例及执行方式；姓名章的权属和用途单核。仍需鉴定或质证的争议章、印模和原件应先保全，不建议当事人自行销毁。新旧章及备案状态未厘清时，不能用销毁替代治理或证据审查。

建立经营可用性方案：合法交接、受监督封存/使用、权限登记、必要付款和开票安排；方案以授权或法院裁定为前提，不能强抢证照、擅自断网银或替法院决定保管人。

最高法发布的外商投资典型案例中，法院曾禁止原法定代表人使用、重刻或隐匿印章，并命其向指定第三方移交公司资料。使用该案例时必须注明其系典型案例且事实包括独资股东决定、董事会决议、拒绝交接和持续对外行为；它说明可以设计具体的行为保全措施，不证明一般控制权争议均应准许保全。

## 民刑行衔接

2026年9月22日起施行的民刑交叉司法解释见[专项来源卡](control-sources.md)。出现涉嫌伪造线索时分别核刑事受案、立案、侦查、起诉、裁判状态；不能把“私刻”措辞或报案回执当定罪证明，也不能以报案自动暂停民事诉讼。登记/刻章行政程序的证据与民事权利结论分开。只提出有证据基础的合法维权方案，不以刑事控告作为强迫对方交出股权的工具。

## 判决交付与原物灭失

按民诉法解释2022修正第492—494条（CO14）分别定位：判决指定的特定证照原则上执行原物；确已毁损、灭失时，折价赔偿须双方同意，不能协商一致的依第492条终结执行程序，申请执行人可另行起诉。不得把该项终结与“终结本次执行程序”混称，也不能仅凭被执行人声称遗失就认定原物灭失。

他人持有指定交付物时，申请法院核持有人、发出协助执行通知并依法处理拒交；其主张合法持有时核执行异议。发现隐匿证照或账簿线索时，向法院提交位置、交接及使用记录，由法院依法调查、责令交出或搜查，不由当事人自行强取。补领或重刻与原物交付不是同一义务，不能未经执行依据审查直接互相替代。解释所引旧民诉法条号须映射现行版本。
