# 商事案件专项工作流

商事争议先还原交易，不从单份合同或单个公司名称直接得出结论。按下列顺序工作：

1. [合同链与履行争议](contract-performance.md)：交易结构、文本顺序、履行、变更、解除和余额。
2. [公司、股权与治理](corporate-equity.md)：出资、股权、决议、控制权和关联交易。
3. [授权、印章与表见问题](authority-seals.md)：代表权、代理权、印章、职务行为和追认。
4. [担保、增信与融资](security-finance.md)：保证、抵押、质押、保理及优先顺位。
5. [损失、价款与会计材料](damages-accounting.md)：本金、利息、违约金、损失、抵销和账务证据。
6. [保全、执行与困境企业](preservation-insolvency.md)：财产线索、保全成本、执行顺位和破产风险。
7. [商事仲裁与涉外交易](arbitration-crossborder.md)：仲裁协议、机构规则、法律适用、送达和跨境实现。
8. [商事争议全景分流](commercial-disputes-map.md)：覆盖合同、融资、担保、公司、金融、票据、保险、竞争、破产和涉外商事的统一分流。
9. [公司诉讼全景图](company-litigation-map.md)：决议、出资、股权、知情权、代表诉讼、责任、退出、登记和对外交易。
10. [商事权威来源登记册](authority-registry.json)：记录官方来源、效力层级、核验状态、专题标签和使用边界。
11. [公司登记、证照与裁判衔接](registration-remedies.md)：区分证照返还、决议诉讼、虚假登记撤销、裁判后登记撤销、行政救济与执行涤除。

可执行 `python scripts/search_commercial_authorities.py --keyword 公司法 --limit 5` 检索登记册。结果只表示本地登记命中，不表示法源穷尽或个案结论；`official_source_located` 条目必须在提交前再次核对完整现行文本。

按实际争点形成交易结构图、合同文件链、履行台账、资金台账、授权链、担保与资产图、请求/抗辩矩阵。纯公司治理争议不强制生成无关交易图表，直接进入[控制权专项](control-disputes.md)。发票、印章、对账、付款、工商登记和行政许可都只是证据或法律关系的一部分，不能单独替代全案判断。

当前条文级索引已收录现行公司法、公司法时间效力规定、公司法解释（一）至（五）、市场主体登记管理条例及实施细则、公司登记管理实施办法、民法典总则编解释、合同编通则解释、担保制度解释、民间借贷解释、建设工程施工合同解释（二）、企业破产法及解释（一）至（三）、票据法、票据纠纷司法解释、买卖合同司法解释、执行异议之诉司法解释、保险法及解释（一）至（四）、证券法、证券虚假陈述司法解释、合伙企业法、企业改制纠纷规定、外商投资企业纠纷解释（一）、存单纠纷规定、期货纠纷规定（一）（二）、信用证及独立保函纠纷规定、银行卡民事纠纷规定、融资租赁合同纠纷解释、涉外民事关系法律适用法及解释（一）、（二）、国际条约和国际惯例解释、电子签名法、民事诉讼法解释，以及查封冻结、拍卖变卖、执行程序、执行异议复议、变更追加、财产保全、财产调查、执行和解和执行担保九项执行规则。公司法解释沿用旧公司法条号，执行和金融规则的2020年整合文本亦可能援引修法前法律、监管规范或交易规则，必须按现行公司法、民诉法、金融特别法及时间效力规则核对冲突和条号映射；企业破产法修订草案尚未生效，不得替代现行法。大量商事行政法规、部门规章、交易规则及其他司法解释仍须按争点从官方来源补查并注明版本；登记册已定位的官方来源不能代替完整文本核验。
