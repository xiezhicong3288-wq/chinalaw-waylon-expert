# 商事案件专项工作流

商事争议先还原交易，不从单份合同或单个公司名称直接得出结论。按下列顺序工作：

1. [合同链与履行争议](contract-performance.md)：交易结构、文本顺序、履行、变更、解除和余额。
2. [公司、股权与治理](corporate-equity.md)：出资、股权、决议、控制权和关联交易。
3. [授权、印章与表见问题](authority-seals.md)：代表权、代理权、印章、职务行为和追认。
4. [担保、增信与融资](security-finance.md)：保证、抵押、质押、保理及优先顺位。
5. [损失、价款与会计材料](damages-accounting.md)：本金、利息、违约金、损失、抵销和账务证据。
6. [保全、执行与困境企业](preservation-insolvency.md)：财产线索、保全成本、执行顺位和破产风险。
7. [商事仲裁与涉外交易](arbitration-crossborder.md)：仲裁协议、机构规则、法律适用、送达和跨境实现。

每个案件至少形成交易结构图、合同文件链、履行台账、资金台账、授权链、担保与资产图、请求/抗辩矩阵。发票、印章、对账、付款、工商登记和行政许可都只是证据或法律关系的一部分，不能单独替代全案判断。

当前本地库未收录企业破产法、证券法、票据法、保险法、合伙企业法、涉外民事关系法律适用法及大量商事司法解释。命中这些领域时必须从官方来源补查并注明版本。
