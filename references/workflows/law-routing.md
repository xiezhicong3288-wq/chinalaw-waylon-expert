# 法域与特别法路由

法律关系或适用法不明确时，按争点检索本文件的相关段落；已明确法律和条号的原文查询无需加载。以下保留各专题的特别法、版本及证据核验要求。

- 民事请求权、合同、物权、人格权、婚姻继承、侵权：民法典；涉及权利滥用、意思表示瑕疵、无权代理、表见代理或诉讼时效时追加民法典总则编解释。
- 不动产登记、预告登记、裁判导致物权变动、共有份额优先购买或善意取得：并读民法典物权编解释（一）；分开审查基础合同效力、登记或交付、公示状态、受让时点、善意及重大过失和举证责任，不把登记簿记载直接等同于真实权利状态。
- 买卖合同成立、交付、检验、所有权保留、逾期付款与抗辩：民法典合同编，并检索买卖合同司法解释；公司主体还要核对代表权、代理权和印章证据链。
- 建设工程施工：并读建设工程解释（一）与2026年解释（二），先按新解释第二十三条核施行日、一审受理时点和冲突规则。实际施工人向发包人请求时区分借用资质、转包违法分包、代位权及农民工工资，不把旧解释第四十三条扩大为所有实际施工人均可直接追索；结算鉴定、质量工期及优先受偿范围和期限按对应条文逐项核证。
- 民事立案、管辖、保全、审理、上诉、再审、执行、涉外程序：民事诉讼法及其解释；证据问题同时加载民事证据规定。财产控制与实现按阶段追加查封冻结、拍卖变卖、财产保全、财产调查、变更追加、执行和解或执行担保规则。案外人或申请执行人对执行标的提出实体排除主张时，同时核对执行异议复议规定与执行异议之诉司法解释，区分异议审查、十五日起诉期、确权或给付合并请求、继续执行及破产衔接；旧文本援引的民诉法条号须映射到现行法。
- 公司设立、出资、股权、治理、董监高责任、解散清算：公司法；先用公司法时间效力规定锁定法律事实和持续履行时点，再按争点检索公司法解释（一）至（五），并对旧法条号做现行公司法映射。决议争议优先核对解释（四）第一至六条；关联交易、董事解除和重大分歧优先核对解释（五）。涉及登记事项、申请签署、营业执照、虚假登记、裁判后撤销或协助执行时并读市场主体登记管理条例、实施细则、公司登记管理实施办法和运行时有效的统一登记文书、材料规范；登记受理或公示不替代内部决议和民事权利判断。合同或侵权问题再加载民法典。
- 公司担保、债务加入及增信：民法典、合同编通则解释和担保制度解释并用；逐项核对公司决议、相对人合理审查、越权代表、善意及法律后果。
- 企业破产、重整、和解、清算与执行衔接：企业破产法及解释（一）至（三）；先核对受理时点、管理人接管、印章账簿移交、保全解除、个别执行中止、取回抵销、撤销和债权顺位。修订草案不得替代现行法。
- 汇票、本票、支票：票据法与票据纠纷司法解释并用；分开审查票据关系和基础关系、签章真实性与形式、背书连续、善意与抗辩、权利期间、付款请求、追索、失票救济、保全及涉刑程序。
- 保险合同：保险法及保险法解释（一）至（四）；重点核对时间效力、险种、保险利益、代签追认、如实告知、格式条款提示说明及其举证、受益人、承保范围与免责、事故通知、理赔材料、核定给付期限、危险增加、代位求偿和责任保险第三人请求，另查现行监管规则。
- 证券发行、交易和虚假陈述：证券法及证券虚假陈述司法解释；区分信息披露义务人、控股股东及实际控制人、董监高、保荐承销与服务机构责任，依次审查重大性、交易因果关系、过错、实施/揭露/更正日、损失与系统风险等其他原因、诉讼时效和代表人诉讼。
- 存单、期货、信用证和独立保函：分别加载对应司法解释；先确认交易类型和账户或单据法律性质，再审真实性、独立性、保证金隔离、风险通知、强行平仓、欺诈例外、善意第三人及止付门槛，并补查现行金融监管和交易所规则。
- 银行卡民事纠纷：加载银行卡民事纠纷规定，分开审查格式条款提示说明、利息费用与违约金、真实交易或盗刷、身份与交易验证、发卡行或支付机构的系统记录和证据保存、持卡人保管过错及多主体责任；证据缺失时核对具体控制主体和举证不能后果。
- 融资租赁：民法典融资租赁合同、担保制度解释和融资租赁合同纠纷解释并用；先按交易实质定性并审查售后回租、租赁物权属和登记，再区分全部未付租金与解除收回的救济选择，计算收回物价值、残值和损失，处理买卖与租赁关系的第三人参加。
- 普通合伙、特殊普通合伙和有限合伙：合伙企业法；分开审查合伙协议与法定规则、内部表决、事务执行和对外代表、善意第三人、入退伙结算及不同合伙人的债务责任。
- 企业改制或外商投资企业纠纷：还原改制、资产债务承接、投资和登记结构；按企业改制规定、外商投资企业纠纷解释（一）、公司法和外商投资法审查债务承担、实际投资者、名义股东、股权变动及准入规则。
- 民间借贷：民法典借款合同规则与民间借贷司法解释并用；分开证明借贷合意、交付、资金来源和流向，审查基础关系抗辩、虚假诉讼迹象、主体用途、法定代表人借款、担保身份、本金扣息及不同时间段的利率保护标准。
- 涉外合同、侵权、物权或主体问题：涉外民事关系法律适用法及解释（一）、（二），必要时追加国际条约和国际惯例解释；分开判断涉外性、特别冲突规范、可否明示选法、强制性规定、公共利益、外国法查明责任和条约适用状态。
- 电子合同、电子印章、平台点击签署和数据电文：电子签名法与民事证据规定并用；电子形式不当然证明签署主体、权限、内容完整或送达，须核生成与控制、签后改动、系统日志、认证证书及代表代理链。
- 劳动关系：劳动法、劳动合同法、社会保险法；先识别劳动关系、仲裁前置和时效，但未收录的劳动争议程序依据必须联网核验。
- 行政处罚与救济：行政处罚法、行政复议法、行政诉讼法，按决定作出、复议、诉讼阶段区分。
- 犯罪构成和刑罚：刑法；侦查、强制措施、辩护、证据、审查起诉和审判程序：刑事诉讼法。不得把证据不足写成有罪，也不得提供逃避侦查、毁灭证据或妨害作证的方法。
- 仲裁协议、仲裁程序、撤销或执行仲裁裁决：仲裁法；同时核验约定的仲裁规则和机构现行规则。
- 垄断、不正当竞争、消费者争议：对应特别法，并检查是否与民法典、公司法或程序法并用。预付式消费追加预付式消费司法解释，审查实际经营者、允许使用营业执照或名义者、场地出租者过错、格式条款、解除与七日退款、余额利息、恶意逃避退款、惩罚性赔偿和经营者控制证据；先核是否属于解释适用范围。
- 宪法问题：说明宪法原则和国家机构规范，不未经依据把宪法条文直接转化为普通民事请求权。
