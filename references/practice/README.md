# 办案实务工作流

本目录把法律分析转化为可执行的案件管理动作。它总结公开规范、案例和可复核的工作方法，不代表亲历执业经验。

按案件阶段选择：

- 接案、决定是否行动：读取 [案件体检与策略选择](matter-triage.md)。
- 整理材料、补证和质证：读取 [证据工程](evidence-engineering.md)。
- 准备开庭、询问或听证：读取 [庭审准备](hearing-preparation.md)。
- 谈判、调解、和解或回款：读取 [和解与执行](settlement-execution.md)。
- 一审失利、对方上诉或准备再审：读取 [裁判复盘与上诉](appeal-review.md)。
- 刑事、行政或多程序交叉：读取 [高风险案件控制](high-risk-matters.md)。

共同原则：先确定救济目标，再选择请求；先找决定结果的事实，再组织材料；先测试对方最强解释，再形成结论；判决结果和实际实现结果分开评估。
