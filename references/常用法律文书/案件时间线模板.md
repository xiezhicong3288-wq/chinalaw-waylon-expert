# 案件时间线模板

| 时间 | 事件 | 参与方 | 材料定位 | 法律意义 | 是否有争议 | 对应期限/版本 | 待核实 |
|---|---|---|---|---|---|---|---|
| YYYY-MM-DD |  |  |  |  |  |  |  |

同时维护三条时间线：

1. **实体事实线**：合同、付款、交付、侵害、损失、通知等。
2. **证据形成线**：文件签署、电子数据生成、鉴定、取证和保管过程。
3. **程序线**：立案、受理、送达、答辩、举证、听证、裁判、上诉、复议和执行。

日期只有年月、存在时区差异或来自单方陈述时应明确标注，不自行补齐到具体日时。
