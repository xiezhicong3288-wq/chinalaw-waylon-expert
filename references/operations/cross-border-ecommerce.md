# 跨境电商：先分流，再核出口与目的地规则

用于境内主体经电商渠道向境外销售商品或服务。先确认经营主体和交易发生地、平台经营者或平台内卖家、自建站与否、目的国家或地区、货物及海关编码、境内出口/境外仓/退运路径、合同与收付款主体、客户数据流。若有中国境内销售，另行处理其国内交易；不能因为只向境外消费者销售，就推断中国《电子商务法》完全不适用，也不能把中国国内消费者退货、产品标识等规则直接当成目的地规则。

| 判断层 | 已定位的正式依据与核验边界 |
|---|---|
| 交易与主体 | [《电子商务法》工信部转载](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_fa48eb1becd2411eabf4081c716b62f6.html)：2018年通过；本次核第2、9、71—73条。第2条限定中国境内电子商务活动，71—73条规定跨境电商促进和监管衔接。须按具体活动和主体核适用，平台义务不能直接套平台内卖家。2026年修正草案征求意见稿不是现行法。 |
| 出口资格与货物 | [《对外贸易法》2025修订·商务部转载](https://scjss.mofcom.gov.cn/wmypzhx/qghd/art/2026/art_ff27f654a22e47d7ba2a74338f780f9e.html)：全国人大常委会2025-12-27公布、2026-03-01施行；本次核第2、11、16—25、37—38条。按货物、技术或国际服务贸易区分；许可、检验、原产地与禁止限制清单另核具体商品，不假设所有出口均须许可。再查[《海关法》商务部法规库](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=90358)、[《进出口商品检验法》市场监管总局转载](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_c7eb1ede24c3424795bbcf3c7e6bb60a.html)及当前海关监管方式公告。 |
| 特殊管制 | [《出口管制法》中国人大网](https://www.npc.gov.cn/c2/c30834/202010/t20201017_308277.html)与现行物项清单；先识别物项、最终用户和最终用途，不能把普通货物统一认定为受控物项。 |
| 出口税务与退货 | 按主体、报关离境、会计销售、出口模式和凭证核[2026年出口货物增值税、消费税退（免）税政策·税务总局](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5247437/content.html)；不能把全部销售写成自动退税。退运、海外仓和不同监管代码须核当期海关及财税公告。[《关税法》商务部转载](https://fdi.mofcom.gov.cn/come-falvfagui-con.html?id=11403)中的跨境零售**进口**规则不能套用于纯出口。 |
| 个人信息与数据 | 先画清境内外收集、存储、访问和提供路径，再核《个人信息保护法》及[《促进和规范数据跨境流动规定》国家网信办正文](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)第4—10条。部分情形可免安全评估、标准合同和认证，但第10条的告知、单独同意、影响评估等法定义务仍须逐项核对；不能说“跨境电商一律免审”。 |
| 目的地与平台 | 商品准入、认证和标签、消费者退货、税务、广告、隐私、知识产权、平台店铺和账户规则须按目标市场及实际平台另查。没有确定国家、地区、商品和平台前，不给单一通用结论。 |

证据导航：营业与店铺主体、商品与成分/用途、销售国家、平台协议、贸易合同、报关单与运单、检验/许可及原产地材料、发票与结算、退税/退运凭证、数据流图和客户告知文本。上述链接是来源导航，未作为法律全文入库；2026-09-29核对了所列范围，应用于个案时复核版本与主管机关后续公告。
