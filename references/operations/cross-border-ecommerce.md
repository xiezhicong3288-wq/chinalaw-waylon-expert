# 跨境电商：先分流，再核出口与目的地规则

用于境内主体经电商渠道向境外销售商品或服务。先确认经营主体和交易发生地、平台经营者或平台内卖家、自建站与否、目的国家或地区、货物及海关编码、境内出口/境外仓/退运路径、合同与收付款主体、客户数据流。若有中国境内销售，另行处理其国内交易；不能因为只向境外消费者销售，就推断中国《电子商务法》完全不适用，也不能把中国国内消费者退货、产品标识等规则直接当成目的地规则。

| 判断层 | 已定位的正式依据与核验边界 |
|---|---|
| 交易与主体 | [《电子商务法》工信部转载](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_fa48eb1becd2411eabf4081c716b62f6.html)：2018年通过；本次核第2、9、71—73条。第2条限定中国境内电子商务活动，71—73条规定跨境电商促进和监管衔接。须按具体活动和主体核适用，平台义务不能直接套平台内卖家。2026年修正草案征求意见稿不是现行法。 |
| 出口资格与货物 | [《对外贸易法》2025修订·商务部转载](https://scjss.mofcom.gov.cn/wmypzhx/qghd/art/2026/art_ff27f654a22e47d7ba2a74338f780f9e.html)：全国人大常委会2025-12-27公布、2026-03-01施行；本次核第2、11、16—25、37—38条。按货物、技术或国际服务贸易区分；许可、检验、原产地与禁止限制清单另核具体商品，不假设所有出口均须许可。再查[《海关法》商务部法规库](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=90358)、[《进出口商品检验法》市场监管总局转载](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_c7eb1ede24c3424795bbcf3c7e6bb60a.html)及当前海关监管方式公告。 |
| 特殊管制 | [《出口管制法》中国人大网](https://www.npc.gov.cn/c2/c30834/202010/t20201017_308277.html)与现行物项清单；先识别物项、最终用户和最终用途，不能把普通货物统一认定为受控物项。 |
| 出口税务与退货 | 按主体、报关离境、会计销售、出口模式和凭证核[2026年出口货物增值税、消费税退（免）税政策·税务总局](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5247437/content.html)；不能把全部销售写成自动退税。退运、海外仓和不同监管代码须核当期海关及财税公告。[《关税法》商务部转载](https://fdi.mofcom.gov.cn/come-falvfagui-con.html?id=11403)中的跨境零售**进口**规则不能套用于纯出口。 |
| 个人信息与数据 | 先画清境内外收集、存储、访问和提供路径，再核《个人信息保护法》及[《促进和规范数据跨境流动规定》国家网信办正文](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)第4—10条。部分情形可免安全评估、标准合同和认证，但第10条的告知、单独同意、影响评估等法定义务仍须逐项核对；不能说“跨境电商一律免审”。 |
| 目的地与平台 | 商品准入、认证和标签、消费者退货、税务、广告、隐私、知识产权、平台店铺和账户规则须按目标市场及实际平台另查。没有确定国家、地区、商品和平台前，不给单一通用结论。 |

证据导航：营业与店铺主体、商品与成分/用途、销售国家、平台协议、贸易合同、报关单与运单、检验/许可及原产地材料、发票与结算、退税/退运凭证、数据流图和客户告知文本。上述链接是来源导航，未作为法律全文入库；2026-09-29核对了所列范围，应用于个案时复核版本与主管机关后续公告。

## 美国目的地：销售争议先分企业买卖与消费者订单

先核签约及收款主体的营业地、买方购买用途、货物还是服务、订单和平台条款、约定的法律及争议解决方式、发货与交付州、实际被诉主体。目的地是美国本身不能决定合同准据法、管辖法院或所有州的消费者保护义务。

**企业间货物买卖。** [联合国《国际货物销售合同公约》正式文本](https://treaties.un.org/doc/Treaties/1988/01/19880101%2003-03%20AM/Ch_X_10p.pdf)第1(1)(a)、2—6条与[缔约及保留状态](https://treaties.un.org/doc/Publication/MTDSG/Volume%20I/Chapter%20X/X-10.en.xml)显示：中美营业地分处两个缔约国的货物买卖，先审公约是否直接适用、合同是否依第6条排除或变更；两国对第1(1)(b)项有保留，不能只因冲突规范指向某缔约国法律就无条件援引该项。中国2013年撤回的是书面形式相关保留，不是第1(1)(b)项。公约第3—5条另限定加工/服务为主、合同效力、所有权效果和人身伤害责任；这些事项回到相应准据法。中国法院审条约保留和允许的协议排除时还应查[法释〔2023〕15号第1、3条](https://www.court.gov.cn/zixun/xiangqing/421922.html)。

**美国消费者零售订单。** 公约第2(a)条原则上排除为个人、家庭或家用购买的货物，但保留卖方订约前或订约时不知道、也无理由知道该用途的例外；不能把所有美国订单一律归入或排除公约。[美国联邦贸易委员会16 CFR Part 435规则入口](https://www.ftc.gov/legal-library/browse/rules/mail-internet-or-telephone-order-merchandise-rule)说明网络商品订单的发货时间陈述须有合理依据，不能按承诺期发货时应依规则处理延期同意或未发货退款；须再核交易是否受该规则约束及当期规则正文。商品陈述与质量保证还须按适用州法查，例如[纽约州UCC §2-313](https://www.nysenate.gov/legislation/laws/UCC/2-313)规定事实承诺、描述或样品在交易基础中的明示保证条件，不能把纽约州法推广为美国各州统一法。平台退款、拒付和账户处理另核有效版本的合同及通知记录。

**质量、退款与诉讼请求。** 若公约适用，按第35、38—40、45—50条分别查合同质量标准、到货检验、说明瑕疵性质的通知及其时间、卖方已知未披露事实、维修/替换、减价、损失和第25、49条解除门槛。第39(2)条的两年是货物不符通知上限（并有约定保证期条件），不能当成统一起诉时效；第40条可限制知情未披露卖方援引第38、39条。把订单、产品页版本、样品、检验、物流签收、首次投诉、客服与售后、退款和支付记录按批次连起来，逐项比较退款、维修、折价和赔偿的证据与执行可行性。

[最高法（2014）民申字第266号公开裁定及CLOUT 1775号摘要](https://cicc.court.gov.cn/html/1/218/347/329/428/430/12754.html)涉及中国卖方与美国企业买方的设备质量争议。最高法确认双方营业地分处缔约国且未排除公约，并认为买方未充分证明不可修复的质量缺陷；同页案例摘要还记录了下级法院对瑕疵通知的判断。故障、报关或票据瑕疵不能脱离合同目的和证据直接推导全额退款。该案是设备和售后服务的具体事实，不能直接套用到美国消费者零售；摘要不是另一个判决。[指导案例107号](https://www.court.gov.cn/shenpan/xiangqing/143372.html)则提示比较货物能否合理使用或转售、实际损失与所选救济，不把任何瑕疵直接等同根本违约。

本卡2026-09-29实际核对联合国公约英文文本第1—6、25、35、38—40、45—50条及条约保留记录，最高法条约解释第1—9条、上述案例公开页面与FTC规则摘要、纽约州UCC §2-313；未全文收入公约或美国法。美国其他州法、平台协议、具体商品监管、法院管辖及跨境判决执行均未核，按争点另查，不据来源卡声称美国商事法律已覆盖完整。
